Sistemas de ecuaciones con nombres propios

Define tus incógnitas, tus variables conocidas (con valor explícito o implícito) y luego el sistema de ecuaciones que las relaciona. Todo se resuelve en tu navegador, incluyendo números complejos.

1 · Variables desconocidas

Nombra las incógnitas del sistema (ej. x1, x2). El número de ecuaciones más abajo se ajusta automáticamente a esta lista.

2 · Variables conocidas

Una definición por fila. Forma explícita: a=12. Forma implícita: 3*b=\ln(3/2) (se despeja automáticamente la variable nueva). Puedes usar variables conocidas ya definidas arriba en filas posteriores.

3 · Sistema de ecuaciones

Una ecuación por incógnita. Si no escribes =, se asume = 0. Multiplicación explícita con *; valor(expr) y (expr)(expr) se interpretan como multiplicación implícita. Operadores: + - * / ^. Funciones LaTeX (aceptan llaves o paréntesis): \ln{x} / \ln(x), \log_10{x}, \sqrt{x}, \exp{x}, constante \pi. Trigonométricas directas: \sin \cos \tan \cot \sec \csc. Inversas: \asin \acos \atan \acot \asec \acsc. Hiperbólicas: \sinh \cosh \tanh \coth \sech \csch (y sus inversas \asinh \acosh \atanh \acoth \asech \acsch). Reservados: e (Euler) y j (unidad imaginaria).
